# Fulfillment Workflow — Fiverr SEO Content Service
**Version:** 1.0  
**Effective Date:** Launch Day  
**Owner:** Victoria Excalibur  
**QA Owner:** Justina

---

## Overview

```
ORDER RECEIVED → INTAKE → BRIEF → PRODUCTION → QA → DELIVERY → REVISIONS → CLOSE → REVIEW
     ↑                                                                                |
     └──────────────────────────────── FEEDBACK LOOP ─────────────────────────────────┘
```

**SLA Summary:**
- Intake response: 1 hour
- Brief confirmation: 4 hours
- Delivery: Tier-based (48hrs / 72hrs / 5 days)
- Revision turnaround: 24 hours
- Communication: Daily during active orders

---

## Stage 1: Client Intake (Order Received)

### Trigger
New order notification from Fiverr

### Actions
1. **Welcome Message** (Template — send within 1 hour)
   ```
   Hi [Name],
   
   Thanks for ordering my [Tier] package! I'm excited to create performance-driven SEO content for you.
   
   To get started, please complete this brief form: [LINK]
   
   It takes 5 minutes and ensures I deliver exactly what you need.
   
   Best,
   [Name]
   ```

2. **Deliver Intake Form**
   - Google Forms link
   - Fields required:
     - Topic / subject matter
     - Primary keyword + 2-3 secondary
     - Target word count (confirm matches tier)
     - Tone (professional, casual, authoritative, etc.)
     - Target audience description
     - 2-3 examples of content you like
     - Internal links to include (if applicable)
     - Call-to-action desired
     - Any specific requirements

3. **Set Internal Deadline**
   - Buffer 12-24 hours before Fiverr deadline
   - Add to tracking sheet

---

## Stage 2: Brief & Alignment (Within 4 Hours of Intake)

### Actions
1. Review completed intake form
2. If unclear: Ask clarifying questions via Fiverr message
3. Confirm scope matches purchased tier
4. Send confirmation message:
   ```
   Thanks for the detailed brief! Everything looks clear.
   
   Deliverable: [X words on Topic]
   Target keyword: [Keyword]
   Delivery: [Date] by [Time] EST
   
   I'll send the first draft by then. Feel free to message with any questions!
   ```

4. Update tracking sheet

## Stage 5: Revision Cycle

### Policy (Must Be Clear in Gig FAQ)
- **2 revision rounds included** with every order
- Revision requests must be **specific** (not "make it better")
- New direction / scope change = additional fee
- Turnaround: 24 hours
- **3rd round+:** Quote $15-30 fee depending on scope

### Round 1 Process
```
Client sends feedback
    ↓
Acknowledge within 6 hours
    ↓
Revise per specific feedback
    ↓
Submit Draft 2 within 24 hours
```

### Round 2 Process (Final Polish)
```
Minor tweaks only
    ↓
Submit Final within 12 hours
    ↓
Request approval
```

### Dispute/Escalation
- Unreasonable requests → Victoria escalation
- Scope creep → Quote additional fee
- Client unhappy after 2 rounds → Offer partial refund or full revision (Victoria decision)
